# Artwork and media

Dustfall uses its existing generated visual/audio set. Gameplay does not call paid generation services, and guests do not need provider accounts.

| Material | Origin | Location |
| --- | --- | --- |
| Stage, twenty portraits and three evidence props | AI-generated raster illustrations, optimized for the web | `public/assets/` |
| Five screen concepts | AI-generated layout explorations; concepts, not working UI captures | `docs/design/mockups/` |
| Gameplay screenshots | Browser captures of the running app | Reviewed subset in `docs/screenshots/` |
| Eleven story/event/ending films | Existing Higgsfield films using cast and prop references | Public streams and timed cues in `public/media/cinematics.json` |
| Thirteen host announcements | Existing ElevenLabs recordings; Arthur — Engaging Southern Cowboy | `public/media/narration.json`, local MP3/VTT files in `public/media/narrator/` |
| English, Spanish and Brazilian Portuguese captions | Timed speech/sound captions and translations | `public/media/captions/` and cue arrays |

Films cover the opening, five act intros, clue discovery, voting and three outcomes: caught, wrong accusation or tied accusation. Anonymous ensemble/ending staging allows the live game to supply the actual culprit and verdict. Native English film speech, music and effects are retained. Narration is English; all three caption languages are available without creating new voices during a party.

MP4s stream from their existing public CDN addresses; no movie MP4 is stored in this repository. Narrator MP3s, captions, optimized portraits and stage art are local. Provider credentials, consent screenshots, billing records and generation-account production logs are excluded from public source staging.

README gameplay images show the public stage, language choice and sealed participation. Its separate concept gallery labels all five generated mockups. Private dossiers, recovery codes and solutions are absent from those selected real captures. The film library’s endings and server story source contain spoilers.

During media outages, the stage/controls stay readable, narration offers spoken text, and films expose native controls plus skip/replay. Phone captions follow the active TV’s reported clock, including pause, buffering and replay; stale reports are not current speech. The attention countdown precedes shared moments without adding another soundtrack.
